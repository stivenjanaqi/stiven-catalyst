# stiven-catalyst
Modern publication platform for leadership, operations, management insights, field notes and personal projects by Stiven Janaqi.

## Notes
- Header, footer and `<head>` are identical on every page. When adding a page, copy them from an existing one and set `aria-current="page"` on its nav link.
- Social previews use `social.png` and absolute URLs for `https://stivenjanaqi.github.io/stiven-catalyst/`. If the site moves to a custom domain, update the `og:` tags.
- `fonts/` holds Archivo Black (SIL OFL), used only on devices without Arial Black (Android, Linux).
